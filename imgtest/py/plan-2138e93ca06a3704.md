# imgtest 焊线检测 GUI（app-gpt 布局）

把 imgtest/wire_inspect.py 算法改成"独立模板图 + 多线 + 半自动产品配置 + µm 阈值"，并在 imgtest/ 根目录做一个按 app-gpt 布局的 PySide6 复核程序。

## 范围（已确认）
- 位置：`imgtest/` 根目录（`main.py`、`core/`、`ui/`）。
- 工具栏：导入文件夹、最近文件夹 | 开始检测、停止、重新检测全部、清除标记 | 保存报告(CSV) | 产品下拉 + 新建产品 / 编辑产品 | 自动显示最新 | 操作员。
- 复核照搬：缺陷表（确认/误报/删除/改类型/手动框选）、PASS/FAIL、清除判定、判定后自动下一张、备注、`session.json` 自动保存、快捷键。
- 产品库：`imgtest/products/<名称>/tpl.png + product.json`，工具栏下拉选择。
- **不搬**：授权/版本徽章、训练、工程模式、深度方法栏与灵敏度、导入/导出标注、实时监控、帮助、低分候选、设置对话框（阈值放产品配置里）、HTML 报告。

## 布局（照 app-gpt `ui/main_window.py`）
- 左：筛选下拉（全部 / 疑似缺陷 / FAIL / PASS / 未复核 / 未检出候选 / 有未处理候选框）+ 文件树（状态圆点、检测中转圈、`[n]` 缺陷数）+ 图例。
- 中：模式单选 原图 / 增强(CLAHE) / 导线高亮；显示标记；适应窗口(0) / 1:1(1) / 放大 / 缩小 / 缩放%；横幅；`QGraphicsView` 查看器；底部缩略图条（状态底色）。
- 右：信息标签；标签页「缺陷标记」(类型/分数/来源/状态 + 按钮) 和「导线统计」(单元/线号/长度µm/sweep%/端点偏移µm/z/判定 + 导出CSV)；判定组 PASS/FAIL；备注；快捷键说明。
- 状态栏：计数、进度条。
- 颜色、图标（SVG）、状态色、尺寸沿用 app-gpt。

## product.json
```json
{"name": "...", "pixel_um": 10.0, "tpl_size": [220, 150],
 "wires": [{"p1": [79.0, 69.6], "p2": [141.0, 71.0]}],
 "match_thr": 0.6, "polarity": "dark",
 "wire_diam_um": 25, "corridor_um": 70, "end_tol_um": 100, "shift_max_um": 35,
 "sweep_max_pct": 6.0, "z_missing": 6.0, "z_seg": 2.5, "z_ball": 2.5}
```
- 坐标相对 `tpl.png` 左上角，与被测图解耦。
- 运行时换算：`half_w = corridor/pixel_um`，`end_tol`、`shift_max` 同理；`d`（脊线偏移）与 `along`（沿线平均长度）由 `wire_diam_um/pixel_um` 推出，并设下限。
- `pixel_um` 未知时：对话框可输入"单元间距 mm"，用模板匹配算出的单元周期反推。

## 半自动配置流程（product_dialog）
1. 在当前图上框选一个完整单元 → 裁出 `tpl.png`。
2. `auto_wires`：多方向线形匹配滤波（cv2.filter2D，0–180° 每 15°）→ 鲁棒 z 阈值 → `HoughLinesP`（最小长度约 0.15×单元短边）→ 合并共线段 → 端点；焊点1 = 靠暗斑/靠单元中心的一端。
3. 列表 + 预览：显示每根线；可删除、交换方向、点两点手动添加。
4. 填名称、pixel_um（或单元间距）、阈值 → 保存，下拉框自动选中。
5. 预览按钮：用当前设置在整张图上试检测并标注。

## 检测输出 → Session
- 每根 NG 线生成一个 `Defect`（框 = 线走廊外扩），类型映射：MISSING→缺线，BROKEN→断线，SWEEP→线弧异常，BOND1→第一焊点异常，BOND2→第二焊点异常，SHIFT→焊点偏移；分数 = 归一化严重度。
- 状态逻辑同 app-gpt：有未拒绝缺陷 → 疑似缺陷，否则 未检出候选；人工 PASS/FAIL 覆盖。
- 重新检测保留手动框和已复核框（同 app-gpt `set_detection`）。
- session 记录产品名；切换产品后打开旧结果时，在横幅提示"结果来自产品 X"。
